Send a batch of events

Send JSON from your log collector or service. Include a stable external_id to prevent duplicate ingestion on retries.

curl -X POST  \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"events":[
    {"external_id":"evt-12345","event_type":"authentication_failure",
     "observed_at":"2026-11-06T12:30:00Z",
     "event_data":"Multiple failed login attempts for account admin"}
  ]}'

Each event is assessed and stored. Matching events also create manageable alerts. This local rule engine is a triage layer; forward production telemetry only after deploying behind HTTPS with a production server.
